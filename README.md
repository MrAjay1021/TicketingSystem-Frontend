# Ticketing System

A comprehensive ticket management and customer support web application built with the MERN stack (MongoDB, Express, React, Node.js).

## Overview

This ticketing system provides a complete solution for customer support teams to manage tickets, conduct Near real-time chats, configure chatbots, and 
analyze performance metrics. The application consists of a React frontend and a Node.js/Express backend with MongoDB as the database.

The frontend for the Ticketing System application built with React.

## Technology Stack

- **React** - JavaScript library for building user interfaces
- **React Router** - For navigation and routing
- **Axios** - HTTP client for API requests
- **React Hook Form** - For form handling
- **Recharts** - For data visualization and analytics

- ## Available Pages

- **Home** - Landing page for customers
- **Login/Signup** - Authentication pages
- **Dashboard** - Overview for admin and members
- **Tickets** - Ticket management interface
- **Chat** - Near real-time chat interface for customer support
- **Bot Config** - Chatbot configuration (admin only)
- **Teams** - Team management
- **Analytics** - Performance metrics and visualization
- **Settings** - User and system settings

## Component Libraries

The application uses custom components for consistent styling and user experience. Major component categories include:

- **Authentication** - Login and signup forms
- **Dashboard** - Summary cards, stats, and activity feeds
- **Tickets** - Ticket list, details, and status management
- **Chat** - Near real-time messaging interface
- **Forms** - Standardized form components
- **Navigation** - Sidebar, header, and navigation elements
